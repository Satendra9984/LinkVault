## DISCORD — Server Strategy

### Servers to join (join these TODAY, start helping first)

1. **Flutter Community** (discord.gg/flutter-community)
   - Help in #help channel for 1 week before mentioning your app
   - Then post in #showcase: "I built a link organizer with Flutter. Here's the stack + what I learned."

2. **Indie Hackers** (discord.gg/indie-hackers)
   - Post in #share-your-project channel
   - Use the format: Problem → What you built → Current traction → What you're learning

3. **r/productivity Discord**
   - Search for active productivity Discord servers
   - Post in the "tools/apps" or "recommendations" channel

4. **Programming communities** (CS students, bootcamp alumni groups)

### Discord Post Template (for showcase channels)

```
Hey everyone! I just shipped v0.4.0 of my indie Android app — LinkVault.

**What it does:** Save links into named collections. Search, organize, find anything instantly. Works offline.

**Why I built it:** I'm a developer who kept losing important URLs. Browser bookmarks became a graveyard.

**Stack:** Flutter + Supabase + RevenueCat + Clean Architecture + Riverpod

**Current traction:** 100+ downloads, 4 months after launch. Building in public.

**What shipped this version:**
- Fixed signup OTP (was completely broken — every new signup failed silently)
- Account deletion screen (GDPR compliance for Play Store)
- Navigation crash fixes

**Play Store:** https://play.google.com/store/apps/details?id=com.vicharshala.link_vault

Would love any feedback from people who actually deal with link-saving problems. Happy to share what I've learned about the Supabase auth flow if useful to anyone!
```
