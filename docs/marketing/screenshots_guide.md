# Play Store Screenshots Guide — LinkVault v0.4.0

7 screenshots required. Recommended size: 1080 x 1920 px (portrait).
Use Canva or Figma to add caption overlays. Phone frame optional but adds premium feel.

Capture each screen on your physical device (production build) or emulator.
Tools: Android Studio emulator screenshot, or `adb exec-out screencap -p > screen.png`

---

## Screenshot 1 — Home Dashboard

**What to show:** Home screen with 3–4 pinned collections visible, each with thumbnail/icon.
**Caption overlay:** "Everything organized, always at hand."
**Mood:** Clean, orderly. Shows value immediately.

**Steps:**
1. Add 4 collections: "Dev Resources", "Reading List", "Design Inspiration", "Projects"
2. Pin all 4 to the home dashboard
3. Screenshot the home screen
4. In Canva: add caption at bottom in white on a dark gradient strip
